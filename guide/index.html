Install Laxman AI Skills

Use these installable Agent Skills with Google AI Edge Gallery. Each skill is hosted as a folder containing its SKILL.md and runtime.

1

Open Agent Skills

In AI Edge Gallery, open the Agent Skills section and choose the option to add or load a skill from a URL.

2

Copy a skill folder URL

Use the folder URL below. The folder is the install target; the SKILL.md inside it provides the skill definition.

3

Load the skill

Paste the URL into the Gallery's URL loader and confirm the import. After installation, invoke the skill naturally in chat.

4

Verify the skill definition

If import fails, open the skill's SKILL.md URL in a browser. It should be served as a live file from GitHub Pages, not a normal GitHub repository page.

Tip: Network-backed skills need internet access. Local-only utilities can work without an external API key.
