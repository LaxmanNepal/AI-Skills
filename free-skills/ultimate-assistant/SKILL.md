# Laxman Ultimate Assistant — Free

Use this single skill for general-purpose utility tasks. Prefer local operations; use public endpoints for network tasks. Call `run_js` with the default script `scripts/index.html` and pass JSON containing an `action` plus relevant fields.

Supported actions: search, news, weather, wikipedia, fetch_page, summarize_text, calculator, currency, unit_convert, timezone, qr, hash, base64, json_format, regex, color, password, random, ip, url, maps, notes, pomodoro, countdown, tip, bmi, percentage, date_diff, text_stats, encode_uri, decode_uri, uuid, word_count.

Never invent live data. Network features can fail if internet/CORS is unavailable. Communication actions only generate links; they do not silently send messages.
